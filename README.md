## Academic Projects

### Needs Assessment and Requirements Engineering for Clinic Management
Group project (Systems Analysis and Design course) for a multidisciplinary medical clinic, covering reception, consultation, and billing.
- Planning with **5W2H**
- **BPMN** modeling of the current flow (AS-IS) and the proposed automated flow (TO-BE)
- **Tools:** Bizagi Modeler, Astah/Draw.io, Figma

### UX/UI Analysis of the gov.br Portal (Design Thinking)
Group project that walks through the full Design Thinking cycle on the gov.br portal.
- Research, problem definition, **personas**, and **user journeys**
- Ideation and selection of the "Simplified Alternative Login" solution
- **Two-version prototype**, with an evolving accessibility bar (A-/A+, high contrast, and VLibras)
- **Usability test** plan with defined tasks and Markdown documentation on GitHub

### Orders Database in Oracle (BD Pedido)
Series of activities on a physical model with customers, orders, products, salespeople, and inventory, developed in SQL Developer.
- Queries with **joins** and INSERT and UPDATE operations
- **Inventory view** that handles inconsistent data and null values
- **Audit trigger** that logs inserts, updates, and deletes to a log table (with sequence)
- **Procedure and function** for email validation with exception handling

### Object-Oriented Programming in Python
Practical exams modeling class hierarchies.
- Inheritance and **abstract classes** with the `abc` module
- Class attributes and methods, such as counting instantiated objects
- Separation between the class module and the main program

### Web Development with HTML and CSS
Websites built in the Web Systems Development course.
- Semantic HTML with lists, tables, forms, and images
- CSS with selectors, box model, **Flexbox**, **Grid**, positioning, and responsiveness

### Requirements and Usability of a Library System
- **Empathy map** of the "Student" actor (book reservations, group study rooms, and renewals)
- **Use case specification** from a standardized form
